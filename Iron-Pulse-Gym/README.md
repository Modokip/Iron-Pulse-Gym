# Iron Pulse Gym · IPMS (prototipo web)
Abrir `index.html` en el navegador. Cuentas de prueba (clave 1234): dueno@, gerente@, recepcion@, entrenador@, miembro@ ironpulse.com
Los datos se guardan en localStorage (para reiniciar: borrar datos del sitio).

## División del trabajo (un archivo por área)
| Archivo | Área |
|---|---|
| index.html + js/panel.js + css/estilos.css | Acceso, roles y diseño |
| js/db.js | Datos y reglas (Anexo A) |
| js/vistas-recepcion.js | Miembros, membresías, pagos, vencimientos |
| js/vistas-entrenador.js | Rutinas, nutrición, ejercicios |
| js/vistas-gerente.js | Planes, usuarios, reportes |
| js/vistas-miembro.js | Panel del miembro |
